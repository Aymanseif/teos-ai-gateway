   index. It accepts invalid Python and proposes removing required
   parentheses. uv.lock pins the real ruff 0.16.8 with SHA-256 hashes;
   use "uv sync --locked" / "uv run --locked".
2) scripts/update/teos-update and teos-update.cmd download and execute
   code from GitHub. The bundled installer stubs them, but a source
   install ("uv tool install .") leaves them active.

   Code installers: they install the PyPI package, not this TEOS build.
   Use the offline bundle installer or "uv tool install .".

   and uv directories. Only run it if you accept that trade-off.
